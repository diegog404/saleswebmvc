# Sobre

Este projeto é um sistema de relatório de vendas na web, que foi realizado no curso de C# Completo com Orientação à Objetos da Udemy.

## Tecnologias e métodos utilizados

- Linguagens: C#
- Estrutura das páginas: Html, Css e Javascript.
- Frameworks: ASP NET. Core 2.1 e Entity Framework.
- Arquitetura: Padrão MVC.
- Banco de dados: MySQL.
- Modelo de Aplicação: Template Engine com Razor.
